Своя́ онла́йн-за́пись для сало́на / за пять шаго́в. // Без ка́рты / и без программи́ста. / В конце́ покажу́, / что уви́дит клие́нт.
Шаг пе́рвый. / Открыва́ешь сайт / и жмёшь «Попро́бовать».
Второ́й. / По́чта, / паро́ль / и «Созда́ть акка́унт». / Без пи́сем / и подтвержде́ний.
Тре́тий. / Пи́шешь назва́ние, / и а́дрес страни́цы / появля́ется сам.
Телефо́н, / и́мя ма́стера / и «Созда́ть страни́цу за́писи».
Четвёртый. / Услу́ги. / Одна́ кно́пка, / и типовы́е услу́ги с це́нами / уже́ гото́вы. / Це́ны пото́м попра́вишь.
Пя́тый. / Жмёшь «Ссы́лка», / копи́руешь / и ста́вишь её в про́филь.
Всё. // Клие́нт открыва́ет ссы́лку / и ви́дит твой сало́н: / услу́ги, / це́ны / и мастеро́в.
А что́бы он не забы́л, / бот в Телегра́ме / напо́мнит ему́ за су́тки.
Пять шаго́в, / и за́пись рабо́тает. // Две неде́ли беспла́тно, / ссы́лка в про́филе.
