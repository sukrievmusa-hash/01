Клиентка забыла про запись. / Что делать? // Покажу, / как это закрывается.
Сначала запись / должна быть простой. // Клиент открывает твою ссылку / и жмёт на услугу.
Дальше время. // Одно нажатие, / и оно выбрано.
Имя, / телефон / и «Записаться». // Без звонков / и переписки.
Что может пойти не так? // Человек закроет страницу / и забудет.
Поэтому на экране «Вы записаны» / сразу есть кнопка / «Напомнить в Телеграм».
Бот напомнит / за день / и за два часа. // Клиенту это бесплатно.
Всего / три нажатия на запись / и одно на напоминание.
Две недели бесплатно, / без карты. // Ссылка в профиле.
